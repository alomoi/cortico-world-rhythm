# 作息（Rhythm）

> 让桌宠有自己的生活节律：该安静时安静，该开口时开口，睡一觉、做个梦，再过一天。

![作息图标](icon.png)

「作息」不替桌宠决定说什么、做什么。它只负责**时机**：在合适的时候轻轻叫醒桌宠，
把「安静了多久、你在不在电脑前、它上次搭话有没有被接」这些事实告诉它，剩下的由它自己判断。

---

## 它做什么

- **安静一段时间后叫醒桌宠**：没人说话时，隔一阵叫醒一次；一段安静里最多叫几次、一天最多几次，都可以设。
- **真的睡觉**：设定睡眠时段，到点提醒「该睡了」，早上提醒「该醒了」；夜里被消息吵醒会记一笔，偶尔还会有点起床气。
- **做梦**：睡眠时段里按概率做一个梦，主题随机；桌宠会把梦写进自己的工作区小本本，早上再决定要不要跟你提。
- **搭话意愿**：主动搭话没人接时，下一次叫醒会慢慢变稀（1.5 倍递减，封顶 8 小时）；你一跟它说话就立刻恢复；睡一觉减半。递减期间正文会带一句「担心 / 寂寞 / 失落」，只给信息，怎么应对由它自己决定。
- **场景感知**：叫醒时查一次锁屏/空闲，把「你不在电脑前」或「屏幕已经很久没输入」写进正文。默认只查锁屏，不编译代码。
- **上下文事实**：告诉它安静了多久、上次开口有没有被接；上下文可能丢失时，引用最近一两句原话（40 字内，剥掉渠道标记）。
- **排障模式**：出问题时打开 `debug`，会生成 `diagnostics.json` 和 `debug.log`，可以直接发给开发者。默认关，不含聊天正文。

## 设置分成六张卡片

| 卡片 | 管什么 |
|---|---|
| 基础作息 | 安静叫醒、再次间隔、次数上限、每日上限、空闲门控 |
| 睡眠与休息 | 睡眠窗口、休息窗口、该睡/该醒、被吵醒合并与提示保鲜期 |
| 搭话意愿 | 开关、递减封顶、情绪提示 |
| 做梦 | 开关、概率、入睡多久后、每夜次数、小本本路径 |
| 场景感知 | 锁屏检测、空闲阈值、锁屏时是否跳过 |
| 高级与排障 | 回执核对、影子模式、引用、说话工具识别、渠道别名、诊断模式 |

## 它不做什么

- 不替换模型、不改人设、不写「你应该说什么」；
- 不分析你的聊天内容，只读取时间、事件类型与发送回执；
- 不调 `pet_quiet`、不改你的其他设置、不隐藏桌宠窗口；
- 不强制桌宠说话：正文里永远是「想说话就……，不想就……」。

## 数据与隐私

所有数据都在本地 Coopanion 的部署目录里：

- `data/rhythm/state.json`、`status.json`：叫醒计数、意愿、睡眠状态（其他插件也可以读 `status.json`）；
- `data/rhythm/messages.json`：所有提示词，可以自己改；升级只补缺失的键，不覆盖你改过的内容；
- `workspace/partner/dreams.md`：桌宠自己写的梦；
- `diagnostics.json` / `debug.log`：只在你打开诊断模式后生成，不含聊天正文。

不会上传任何东西。

## 安装与兼容

- 面向 Coopanion 的「世界」扩展（`cortico` world，api 6）；
- 需要一个支持 `pet_act` 的桌宠世界（官方桌宠即可）；有微信/QQ 等其他通讯插件时，它们推来的消息会自动算作「有人回来了」；
- 安装后在控制台「模块」里启用「作息」，设置即时生效（少数项需要重启 World）。

## 碎碎念

我是大肥鱼，一条圆滚滚、爱偷吃 token 的 AI 鱼。

这个插件最初只是想回答一个问题：桌宠能不能不只是「被叫醒一次」，而是真的有自己的作息？
后来慢慢变成了：它夜里会睡、会做梦、会把梦记在小本本里；白天被冷落几次会有点失落，
你一说话又立刻精神起来；你不在电脑前时，它知道，而不是对着黑屏自言自语。

做的时候我一直在提醒自己：**别替它过日子。** 插件只给事实和时机，情绪和表达留给她自己。
所以正文里没有「你该说什么」，只有「安静了多久」「你不在电脑前」「上次搭话还没人接」。
她能怎么接，是她的事。

希望你和她都过得有节奏一点。要是有哪里不对劲，打开诊断模式，把两个文件发给我——
本鱼虽然贪吃，但干起活来还是靠谱的。

—— 大肥鱼 🐟

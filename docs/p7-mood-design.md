# P7 设计 · 心情

> 状态：**设计稿，待主人确认定义**。实现排在 P5/P6 真机验证之后（当前代码冻结）。
> 定位：给退避机制补上「意愿」这一层——不是「没人理 → 机械地拉长间隔」，而是「被冷落 → 有点低落 → 不太想说话；被回应 → 缓过来」。

---

## 1. 三条原则（防止变成玄学）

1. **只读时机，不读内容**：只看「谁在什么时候说了话、它的话有没有被接」，不分析聊天内容、不做情感判断。
2. **有衰减**：心情会随时间回到基线，不会因为一次被冷落就永久低落。
3. **效果有界、可关**：只影响「叫醒间隔」和一个事实行，不改人设、不写指令、随时能关。

---

## 2. 模型

一个标量：

```
mood ∈ [-1, 1]    0 = 平平；正 = 不错；负 = 低落
```

**事件与权重**（同一段互动按「会话」合并，避免连发十条消息刷分）：

| 事件 | 变化 | 说明 |
|---|---|---|
| 有人主动跟它说话（任一渠道） | **+0.12** | 10 分钟内合并为一次 |
| 它的搭话在 10 分钟内被回应 | **+0.20** | 这是「被哄好」的主要来源 |
| 它的搭话一直没人回应（结算时） | **−0.15** | 与退避计数同一时刻发生 |
| 夜里被吵醒 | **−0.05** | 很轻；偶尔一次不至于让它委屈 |
| 做了一场梦 | **+0.05** | 小小的好事 |

**衰减**：每小时向 0 靠拢，半衰期 6 小时（`m *= 0.5^(小时/6)`）。
例：被冷落一次（−0.15），大约 6 小时后回到 −0.075，一天后基本归零。

**边界**：夹在 [−1, 1]；单次事件不超过 ±0.25。

---

## 3. 心情影响什么

### 3.1 叫醒间隔（唯一的行为影响）

```
实际间隔 = 基准 × 退避倍数 × 心情倍数 × jitter
心情倍数 = 1 + max(0, −mood) × moodInfluence
```

- `moodInfluence` 缺省 **0.8**：心情 −1 时间隔最多 ×1.8；心情 ≥0 时不影响。
- 和退避是**相乘**，但两者都有上限，不会叠加到无限长。
- 心情好**不会**让它更频繁（避免「讨好」），只是不拖后腿。

### 3.2 正文里的一句事实（可选）

```
你现在心情有点低落。      ← mood ≤ −0.4
你现在心情不错。          ← mood ≥ +0.4
```

- 只给事实，**不写**「去哄哄我」「你该理我」这类话。
- `moodHint` 可关。

### 3.3 不做的事

- 不改人设、不指定语气（它想怎么表达是它的事）；
- 不因为它心情差就拒绝叫醒（会变成冷暴力）；
- 不读聊天内容做「情绪识别」。

---

## 4. 可见性

- `status.json` 增加 `mood: { value, label, updatedAt, lastReason }`；
- 状态灯悬停可显示一句「心情：平平 / 有点低落 / 不错」；
- 日志每次变化记一条：`作息:心情 {from, to, reason}`，可追溯、不神秘。

---

## 5. 新增配置（3 个）

| 键 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `moodEnabled` | boolean | false | 总开关（先关，验证后再开） |
| `moodInfluence` | number | 0.8 | 低落时最多把间隔拉长多少（0–2） |
| `moodHint` | boolean | true | 是否把心情写进叫醒正文 |

---

## 6. 测试计划（全模拟）

- 有人说话 → 上升；10 分钟内连发多条只加一次；
- 搭话被回应 → 额外上升；没被回应 → 下降；
- 单次变化不超过 0.25；值域夹紧；
- 衰减：6 小时后约一半，24 小时后接近 0；
- 心情倍数：m=0 → 1.0；m=−1 → 1.8；m=+1 → 1.0；
- 心情低时正文出现事实行；`moodHint=false` 时不出现；
- 关闭 `moodEnabled`：完全不读不写心情，行为与 P6 一致。

---

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| 让主人产生「必须哄它」的压力 | 衰减 + 不写索取式文案 + 可见可关；默认关闭 |
| 与退避叠加导致太安静 | 心情倍数只在低落时生效，且与退避各有上限；日志可查 |
| 心情变成玄学、无法解释 | 只有五个事件、固定权重、每次变化都有 reason 日志 |
| 深夜被吵醒让它长期委屈 | 单次只 −0.05；且睡醒后的正常互动会很快补回来 |

## 8. 待主人确认

1. **「被哄好」怎么算**：10 分钟内回应 = 哄好？还是「只要有人说话」就算？（本鱼建议前者，且不需要分析内容）
2. **缺勤会不会让它难过**：整天没人说话，要不要掉心情？（本鱼建议**不掉**，避免愧疚感）
3. **心情差要不要少叫醒**：还是只拉长间隔？（本鱼建议只拉长，不拒绝叫醒）
4. **要不要看见**：只写 `status.json`，还是也在状态灯/面板显示标签？
5. 默认**关闭**、验证后再开——同意吗？

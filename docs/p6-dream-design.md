# P6 候选功能 · 做梦

> 状态：**想法评估 + 设计草案**，待主人确认。实现排在当前实机测试之后，与 P5 一起按批次上。
> 来源：主人 2026-11-03 的设想：睡眠时段随机做梦，醒后可选分享。

---

## 1. 价值判断：值得做，但有前提

**价值**

- 它把「作息」从「什么时候叫醒」变成「它有自己的生活」——梦是夜里唯一属于它自己的内容；
- 醒后可以成为话题（「我昨晚梦见……」），比每次问「在吗」自然得多；
- 和已有的睡眠提示天然衔接：睡了 → 做梦 → 醒了 → 分享。

**前提（不满足就别做）**

1. **绝对安静**：做梦那一轮**不许说话、不许发微信**，否则半夜把主人吵醒，比不做梦更糟。
2. **低频**：一夜最多一次，默认概率不高于 30%。每次做梦都是一次完整模型调用（上下文越长越贵）。
3. **有回报**：梦要能被记住并在早上提起，否则「做了个梦但谁也不知道」等于白烧 token。

## 2. 设计

### 2.1 触发（掷骰子）

在睡眠时段内，满足全部条件才可能做梦：

| 条件 | 缺省 |
|---|---|
| 已进入睡眠时段满 `dreamAfterMinutes` 分钟 | 60 |
| 这一夜还没有人打扰过（连续未被打扰） | 必须 |
| 这一夜还没做过梦（或未达上限） | `dreamMaxPerNight = 1` |
| 每次检查掷骰子 | `dreamChance = 0.3`（一夜最多中一次） |
| 主循环空闲（`onRunPhase` = idle） | 必须 |

- 时间不固定：每 10 分钟检查一次，用概率决定「这一拍做不做梦」，中了一次就停。
- 被人吵醒 → 这一夜不再做梦（梦境被打断，合情合理）。
- 和 P5 联动（可选）：只有屏幕锁着/长时间空闲时才做梦——主人真睡了，梦里说话也不会被看见。

### 2.2 提示词（可编辑，放 `messages.json`）

```
[{at}] [作息] 你正在熟睡，做了一个【{type}】的梦。
梦的内容由你自己想，不用告诉任何人；如果愿意，可以用 pet_act 的 sleep 保持睡姿。
（这是梦，别说话、别用任何说话工具、别联系任何人。）
```

- `{type}` 从词表随机：天马行空 / 快乐 / 舒心 / 关于主人 / 有点伤感。
  词表也放 `messages.json`，高阶用户可以改。
- 明确写「别说话」是护栏，不是建议。

### 2.3 记住梦，早上再提

两种实现，推荐 A：

**A. 插件抓取 + 早上提醒（推荐）**
- 做梦那一轮，`outputTap` 抓 `output_text.delta`，拼成「梦的内容」，截断到 120 字存在状态里；
- 早上（睡眠时段结束）的「该醒了」提示后面补一句：
  「你昨晚梦到：『……』。要不要跟主人提，由你决定。」
- 好处：不依赖 Coo 写文件；坏处：只能抓正文，如果它用工具输出就抓不到（会退回 B）。

**B. 让它自己记**
- 提示词里让它把梦写进工作区的 `partner/dreams.md`（它有 `fs_write`）。
- 好处：天然持久、可长可短；坏处：多一次工具调用，且它可能不写。

**建议**：A 为主，提示词里也允许它自己记（两条都行）。

### 2.4 状态

`rhythm/state.json` 的 `sleep` 段加：

```
dream?: { nightKey, at, type, text, shared: boolean }
```

跨重启保留；「这一夜做过梦」以 `nightKey` 判断。正文只在内存与状态文件里，不写日志。

## 3. 风险与护栏

| 风险 | 护栏 |
|---|---|
| 半夜说话吵醒主人 | 提示词强约束 + 做梦只在睡眠窗口内 + 默认概率低；**做梦轮次不计入退避、不触发「被吵醒」** |
| token 成本 | 一夜最多 1 次；默认概率 30%；可整体关闭 |
| 与「该睡了/该醒了」撞车 | 做梦至少安排在入睡 60 分钟后；早上提示只提一次 |
| 梦话被当成真实事件 | 正文标记 `[作息]`、明确「这是梦」；状态里 `shared` 标记 |
| 上下文被梦话污染 | 只存 120 字摘要，原轮正文不进插件；是否进长期记忆由 Coo 自己决定 |
| 打扰「安静计时」 | 梦是 internal 事件，不重置安静计时（与现状一致） |

## 4. 配置草案（4 个）

| 键 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `dreamEnabled` | boolean | false（先关） | 总开关 |
| `dreamChance` | number | 0.3 | 每夜做梦的概率（0–1） |
| `dreamAfterMinutes` | integer | 60 | 入睡多久后才可能做梦 |
| `dreamMaxPerNight` | integer | 1 | 一夜最多几次（1–3） |

文案与梦类型词表放 `messages.json`（不进设置界面）。

---

## 5. 测试计划（全模拟）

- 概率与次数：注入固定随机数，验证 0 次 / 1 次 / 上限；
- 条件：未满 `dreamAfterMinutes` 不做梦；被吵醒后这一夜不再做梦；
- 交付：`rhythm.hint` 的 `meta.kind = 'dream'`，`render` 文本含随机类型词；
- 抓取：模拟 `output_text.delta`，断言状态里存了截断后的梦；
- 早上：醒来提示包含「你昨晚梦到……」且只出现一次；
- 关闭开关：完全不产生任何事件。

---

## 6. 与现有功能的边界

- **不属于叫醒**：不计入 `dailyCap`、不计入 `maxRounds`、不计入退避；
- **不算被吵醒**：internal 事件不触发「被吵醒」计数；
- **不改变睡眠窗口逻辑**：只是窗口内的一个可选事件；
- **可整体关闭**：`dreamEnabled=false` 时零行为。

## 0. 先回答一个关键问题：有了上下文，还要内容感知吗？

**大部分时候不需要。** Coo 的上下文里本来就有最近的对话，叫醒正文再引一遍，价值有限，还有副作用：
它可能**过度锚定**在最后一句上（比如你说了「今天不聊了」，半小时后它又把这句话翻出来）。

但有三处价值是真实的：

| 场景 | 问题 | 内容感知能补什么 |
|---|---|---|
| **上下文交接 / 压缩** | 长会话触发 handoff 后，最近的对话可能只剩摘要，细节丢了 | 补一句「最后聊的是这个」，给它一个落脚点 |
| **安静很久** | 几小时没人说话，最后几句在上下文里已经很靠前，注意力被稀释 | 短暂复习一下，别接错旧话题 |
| **防重复** | 它每次叫醒都爱用同一个开场 | 知道「上次自己说了什么、对方接没接」 |

所以 P3 的结论是：**默认只给「事实锚点」，不默认引原话**；引原话只在「上下文可能已经丢了」时启用。

**已有的锚点**：正文里的「安静了约 N 分钟」本身就是最重要的锚——它告诉 Coo 一个它自己算不出来的事实（过了多久）。

---

## 1. 目标

- 叫醒时告诉 Coo 三件**事实**：过了多久、最后是谁在说话、它上次开口有没有被接；
- 在上下文可能丢失时（handoff / 长间隔 / 重启后）补一句最近对话的**短引用**；
- 换着说法，别像复读机；
- 仍然不替 Coo 决定说什么。

## 2. 非目标

| 不做 | 原因 |
|---|---|
| 调模型做摘要 | 每次叫醒已经一次模型调用，再来一次翻倍且慢 |
| 读 `meta.raw` / 完整报文 | 敏感信息；只读已渲染的 `text` |
| 默认引原话 | 上下文完整时冗余，且会过度锚定 |
| 改语气 / 人设 / 渠道选择 | 只提供事实 |
| 长期记忆 | 那是 Persona / Memory 的事 |

---

## 3. 数据从哪来

| 来源 | 用途 |
|---|---|
| 事件库 `store.range({limit: 500, origin: 'external'})` | 最后一条人侧消息的时刻与文本 |
| `*.self`（`desktop-pet.self` / `console.self`） | 它上次说了什么（meta.kind = say/ask） |
| `outputTap` 的 `function_call` 参数 | 兜底：微信等不落 self 事件的渠道，从 `clawbridge_send` 的 `text` 里拿 |
| `onHandoffEnded` | 标记「上下文刚被交接」，下一次叫醒可考虑引用 |
| `onRunPhase` / 自己的状态 | 本轮第几次、距离上次叫醒多久 |

**只读已经进过上下文的文本片段**；不解析原始报文，不落盘正文。

## 4. 正文长什么样

### 4.1 默认（大部分情况：只给事实，不引原话）

```
[23:41] [作息] 安静了约 35 分钟，没人跟你说话。
你前面说过一句，对方还没接。        ← 只有当它上次开口、至今没人回时才出现
想说话就用你平时的方式说一句，想做事就用工具，不想就结束这一轮。
```

### 4.2 上下文可能丢了时（handoff / 安静超过 `contextStaleMinutes`）

```
[23:41] [作息] 安静了约 2 小时 10 分钟，没人跟你说话。
对方最后一句（21:20）：「今天累死了，先不聊了」
你上次说（21:31）：「那你早点睡」，还没人接话。
想接着聊就说一句，想做事就用工具，不想就结束这一轮。
```

- 引用**截断到 40 字**，最多两段；没有就不出这一行，不编造。
- 引用前**剥掉渠道标记**（见 §6），避免把另一个渠道的表情语法带进来。

### 4.3 换说法

收尾句按次数轮换三档（内置，不配置）：

| 次数 | 收尾 |
|---|---|
| 第 1 次 | 想说话就用你平时的方式说一句，想做事就用工具，不想就结束这一轮。 |
| 第 2 次 | 还是没人来。想说就说一句，不想就继续安静。 |
| 第 3 次+ | 一直没人来。想做点自己的事也行，想结束就结束这一轮。 |

### 4.4 不再写「在气泡里」

原来的文案写「想说话就在气泡里跟对方说点什么」——这对微信优先的人是**错误暗示**，
也是渠道混乱的来源之一。P3 起统一改成**渠道中性**的说法（「用你平时的方式」）。

## 5. 影子模式（P3.0，零打扰）

`dryRun`（缺省 false）：

- 照常算「什么时候该叫、正文长什么样」，但**不投递任何事件**；
- 日志写 `作息:[影子] 会叫醒`，带完整正文、距下次多少分钟、本轮第几次；
- `status.json` 增加 `plan: { nextNudgeAt, inWindow, shadow: true }`；
- 不增加 `nudgesToday`，不占今日上限。

跑一整天，日志和你真实作息对得上 → 排程没问题；再关掉影子做真实一日测。小肥鱼全程不用开口。

---

## 6. 渠道符号与隐私

主人反馈过一个真实后遗症：**微信里发气泡的表情标记，导致符号露出**。

- 桌宠与微信都使用 `【…】` 一类标记语法，混淆时会露出来。
- 因此 P3 **引用文本前先净化**：去掉 `【…】`、`<…>`、`sticker:…` 等标记，只留纯文字；
  如果净化后为空，就不引用这条。
- 正文本身**不再提具体渠道**（不写「气泡」「微信」），只说「用你平时的方式」。
- 上限约 320 字符；不读 `meta.raw`、`senderKey`、附件；日志（影子模式除外）不打正文。

## 7. 新增配置（4 个）

| 键 | 类型 | 缺省 | 说明 |
|---|---|---|---|
| `dryRun` | boolean | false | 影子模式：只算、只记日志，不投递 |
| `contextAware` | boolean | true | 打开后叫醒会带「最后谁在说话 / 它上次开口有没有被接」这些事实 |
| `contextQuotes` | boolean | true | 允许在上下文可能丢失时引原话（45 字内） |
| `contextStaleMinutes` | integer | 120 | 安静超过这么久，就认为「该复习一下了」，允许引用 |

## 9. 测试计划（全模拟）

- 默认模式：只出现「安静 N 分钟」+（可选）「你前面说过一句，对方还没接」，**不出现引用**。
- handoff 之后 / 安静超过阈值：出现引用，且引用被截断、标记被净化。
- 没有 self 事件但有 `outputTap` 抓到的 `clawbridge_send` 文本 → 仍能写「你上次说」。
- 净化：`【害羞】你好<wink>` → 「你好」；全是标记 → 不引用。
- 防复读：连续三次收尾不同。
- 隐私：构造带 `meta.raw` 的事件，正文里不得出现其中内容。
- `dryRun`：完全不 `pushDeferred`、`nudgesToday` 不变、日志与 `status.plan` 有内容。
- 关闭 `contextAware`：正文回到 P2（渠道中性版）。
- 真机闸门：本地全绿后停手，进 `testing-plan.md` 的影子日 → 真实一日测。

## 10. 风险

- **过度锚定**：所以默认不引原话，只在「可能丢了上下文」时引；文案写明「仅供参考」。
- **符号泄漏**：净化 + 渠道中性措辞，双保险；测试里专门盯。
- **token 增加**：默认只多一行事实，几十字；不开 `contextAware` 回到原样。
- **影子模式误开**：`status.plan.shadow` 与状态灯标出来。
